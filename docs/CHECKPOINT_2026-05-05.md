## 1. v0.2.0 deliverables (caveat closures)

### 1.1 Fay-Riddell heat transfer + finite-rate kinetics

`khorium_hypersonic/core/heat_transfer.py`:
  - `fay_riddell_qw` — closed-form q_w with Pr/Le/dissoc enthalpy
  - `boundary_layer_residence_time_s` — τ_res = δ_eq / U_e (Billig-derived)

`khorium_hypersonic/core/kinetics.py`:
  - `cantera_residence_time_ne` — IdealGasConstPressureReactor at τ rather
    than to equilibrium

Together these wire geometry into chemistry through residence time —
the v0.1.0 path had stagnation chemistry geometry-independent because
equilibrium chemistry only depends on (M, T_∞, P_∞).

### 1.2 chemistry_mode parameter on solver

`SolverInput` gained `chemistry_mode: 'equilibrium' | 'kinetics' |
'surrogate' | 'auto'`. `'auto'` tries surrogate (best at high altitude
when v4 weights loaded) → kinetics (Cantera 0D at τ_res) → equilibrium
fallback. `StagnationOutput` echoes back `chemistry_mode_used`,
`residence_time_s`, `q_w_W_per_m2` (Fay-Riddell).

### 1.3 Appleton-Hartree band ordering — RETRACTED as bug

After numerical verification: the "VHF < X-band < Ku" ordering at
hypersonic conditions is **correct collisional Appleton-Hartree
physics**. In the heavily-collisional regime (ν > ω, typical for VHF
through hypersonic sheaths), α scales as √(ω·ω_p²/ν), so α
**increases** with f. In the underdense collisionless regime (ω > ω_p,
ν << ω), α scales as ω_p²·ν / (2cω²) and decreases with f. Both
happen in the same flight at different bands.

Action: upgraded `core/plasma.py` to use the FULL Appleton-Hartree
formula (complex refractive index from n² = 1 - ω_p²/(ω(ω-iν))) so
it correctly handles all three regimes. Paper retracts the bug claim.

### 1.4 CFD sheath wrapper auto-detect

`sheath/from_cfd.py` expanded:
  - Auto-detects SU2-NEMO vs SU2-Euler from vtu field names
    (`Temperature_tr` → NEMO, else Euler+Cantera)
  - Documented OpenFOAM/Eilmer integration via lower-level
    `read_vtu_fields()`
  - Cleaner module docstring covering all three CFD-output paths

### 1.5 Paper

`khorium_hypersonic/PAPER.md` (~3,000 words) + `PAPER.docx` (46 KB,
generated by `scripts/md_to_docx.py`). Sections: Abstract → Background

## 2. v0.3.0 deliverables (major capability upgrade)

Aaron's strategic framing per the positioning doc:
> "CFD tells you what happens. This system tells you what matters —
> and which assumptions are wrong."

The v0.3.0 upgrade is responsive to all four of the strategy doc's
"key improvements needed":
  1. Boundary layer modeling (DONE)
  2. Geometry fidelity beyond R_n (DONE)
  3. Trajectory analysis (DONE)
  4. Uncertainty quantification (DONE)

### 2.1 Boundary layer + viscous heating

`khorium_hypersonic/core/boundary_layer.py`:
  - `air_viscosity` — Sutherland μ(T) for air
  - `fay_riddell_full` — full FR with edge/wall property splits
    (×0.4 / ×0.1 exponents), Pr / Le corrections, dissociation enthalpy
  - `bl_thickness_compressible_laminar(x, U_e, ρ_e, μ_e)` —
    δ(x) ~ √(μ_e x / (ρ_e U_e))
  - `bl_thickness_stagnation(R_n, U_∞, ρ_e, μ_e)` —
    δ_stag ~ √(μ_e R_n / (ρ_e U_∞))
  - `apply_boundary_layer_correction(ne_edge, y, δ, profile, wall_fraction)`
    — smooth ne(y) decay across δ; 'exp' or 'erf' profile, default 5%
    wall_fraction (RAM-C-class)
  - `bl_summary` — one-shot bundle returning q_w + δ_stag + viscosities

### 2.2 Geometry-aware axial flowfield

`Geometry` Protocol extended (in `geometry/base.py`):
  - `axial_stations(n)` → list[float]
  - `local_radius(x_m)` → float
  - `local_curvature(x_m)` → float (1/m)
  - `surface_angle(x_m)` → float (rad, between surface tangent and axis)

Implemented for `SphereCone` (closed-form via curvature math, cosine-
spaced sampling) and `MeshGeometry` (numerical via finite differences).

`khorium_hypersonic/core/flowfield.py`:
  - `oblique_shock_post(M, theta)` — Anderson 2006 Eq. 4.17 iterative
    θ-β-M solver. Returns post-shock state or None if shock detached.
  - `compute_axial_profile(geometry, mach, alt_km, n_stations,
    chemistry_mode)` — walks `geometry.axial_stations(n)`, picks normal
    vs oblique shock per station (30° surface-angle threshold), local
    Billig sheath, residence time, ne.
  - `axial_profile_to_field(profile)` — wraps an `AxialProfile` as an
    `AxisymmetricField` for LOS scan integration. Gaussian or
    exponential radial decay across local δ.
  - `AxialStation`, `AxialProfile` dataclasses with `peak_ne()`,
    `ne_m3`, `tau_residence_s`, `delta_local_m`, `fp_GHz` accessors.

Real-gas T_e for normal-shock stations: uses Cantera enthalpy
equilibration (T_real ≈ 6,200 K at M=22.5, vs frozen 24,000 K). Oblique
stations use frozen T_2 directly (weaker shocks don't bring flow to
rest, so don't apply the chemistry-sink factor).

### 2.3 Finite-rate, geometry-coupled chemistry

`core/kinetics.py` extended:
  - `cantera_residence_time_ne_batch(T_arr, P_arr, τ_arr)` —
    vectorized over arrays using one Cantera `Solution` instance,
    reactor reuse per call. Used by `compute_axial_profile` to evaluate
    50-200 stations efficiently.
  - `select_chemistry_mode(τ, have_cantera, have_surrogate, alt_km)` —
    deterministic mode-selection. Centralised so solver, flowfield, and
    trajectory all behave consistently:
        τ > 1ms             → equilibrium
        v4 surrogate loaded
            AND alt 40-90km → surrogate
        Cantera available   → kinetics
        else                → equilibrium fallback

### 2.4 Trajectory-level simulation

`khorium_hypersonic/solver_trajectory.py`:
  - `TrajectoryPoint(t, mach, altitude_km, AoA)` — waypoint dataclass
  - `solve_trajectory(trajectory, geometry, radar_bands, chemistry_mode,
    aspect_angles_deg, blackout_threshold_dB, debug)` — walks pointwise
    solver per waypoint, assembles `TrajectoryResult`
  - `WaypointResult` — per-timestamp ne, q_w, τ, T_stag, per-band atten
    + status, chemistry_mode_used
  - `BlackoutInterval` — extracts contiguous BLACKOUT runs per band with
    start/end times, duration, peak attenuation
  - `TrajectoryResult.t / .ne_peak_m3 / .fp_GHz / .attenuation_series(band) /
    .status_series(band)` — numpy-array accessors for plotting

### 2.5 Uncertainty quantification

`khorium_hypersonic/uncertainty/monte_carlo.py`:
  - `UncertaintyConfig(n_samples=30, rate_constant_log10_sigma=0.3,
    freestream_density_sigma_rel=0.05, freestream_temperature_sigma_rel=0.03)`
  - `run_monte_carlo(base_request, config, blackout_threshold_dB)` —
    perturbs three independent axes, runs N solves, returns
    `MonteCarloResult` with mean / std / P05/P95/worst (P99) ne, per-band
    atten mean/std, per-band blackout probability.

### 2.6 Public API surface (v0.3.0)

## 3. Validation results

### 3.1 Bluntness sweep at M=22.5 / 61 km (Aaron's headline test)

Increasing bluntness:
  - DECREASES q_w (Fay-Riddell ∝ R_n^(-0.5))
  - INCREASES τ (Billig sets δ; τ = δ/U_e ∝ R_n)
  - INCREASES ne (more time for chemistry)

| vehicle      | R_n   | q_w        | τ      | peak ne   |
|--------------|-------|------------|--------|-----------|
| sharp_narrow |  20mm | 7.45 MW/m² |  1.0µs | 2.5e+19   |
| medium_cone  |  50mm | 5.36 MW/m² |  2.6µs | 6.5e+19   |
| blunt_cone   |  80mm | 4.31 MW/m² |  4.2µs | 1.0e+20   |
| ram_c        | 152mm | 2.70 MW/m² |  7.9µs | 1.7e+20   |
| capsule      | 300mm | 1.92 MW/m² | 15.6µs | 2.6e+20   |

10× spread in ne across geometries. Sharp/capsule q_w ratio = 3.88 =
√(300/20) — exact Fay-Riddell scaling.

### 3.2 RAM-C M=22.5 / 61 km axial profile

8-station axial sweep, kinetics mode:
  x=  0.0mm  normal-shock  T_e=6196K  τ= 7.9µs  ne=1.71e+20  fp=117GHz
  x= 64.1mm  normal-shock  T_e=6196K  τ= 7.9µs  ne=1.71e+20  fp=117GHz
  x=243.8mm  oblique 9°    T_e=1163K  τ= 1.5µs  ne~0
  …
  x=1295mm   oblique 9°    T_e=1163K  τ= 3.0µs  ne~0

ne is geometry-resolved instead of a single value. Peak at the
stagnation point as expected; oblique afterbody too cold for

## 6. What's still pending

### Solver / physics
- **Real-gas oblique-shock chemistry**: oblique stations currently use
  frozen T_2. For accuracy, should also iterate Cantera enthalpy at
  the local edge state. Acceptable approximation for now since oblique
  T is much lower than normal-shock T anyway.
- **Multi-component / non-convex geometry**: `MeshGeometry`'s
  `body_radius_at_axial_station` returns max-radial-distance among
  surface points within ±0.5% of x. Doesn't handle multi-component
  bodies or strongly non-convex shapes. Open issue.
- **No real-time CFD coupling**: top-K mechanism search candidates
  should still go through SU2-NEMO MPI on the GCP VM for
  paper-quality validation.
- **Antenna / link-budget layer**: solver outputs per-aspect-per-band
  attenuation. Real signal-processing evaluation also needs antenna
  gain pattern, vehicle attitude, ground-station look angle, and
  atmospheric refractivity. Out of scope for this package.

### KhoriumBackend integration
- Memory says no upstream pushes to KhoriumAI/*. Package is on
  origin/master at `yardeli/cadpipe-neural-network`; integrators
  should `pip install -e` from that repo or vendor the
  `khorium_hypersonic/` directory.
- FastAPI router (`khorium_hypersonic.api.create_router`) exists but
  hasn't been validated against an actual KhoriumBackend instance.

### Validation / artifacts

3. **AI-exhaustive search demo**. The headline differentiation per
   Aaron's strategy doc. Run `exhaustive_search` on a ≤24-reaction

   max-radial-distance with a raycasting-based axial profile that
   handles non-convex bodies (HGV waveriders, scramjet inlets, etc.).
